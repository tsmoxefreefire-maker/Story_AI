## 1. الفكرة بجملتين

الموديولات 1 لـ 5 بيكتبوا القصة: الدرس ← المفاهيم ← فكرة القصة ← السكربت (مين بحكي شو) ← الشخصيات والأماكن.
**الموديول 6 بياخد هاد كله وبطلّعه قصة بتشتغل**: صوت لكل جملة، رسمة لكل مشهد، حركات متزامنة مع الكلام، فعاليات للطالب، وكلّه بملف `index.html` واحد + ملفات صوت. وبعدين **بيفحصها بمتصفح حقيقي، بيصلّح اللي فيه غلط، بينشرها، وبيستقبل تعليقات المراجعين وبيعمل نسخة معدّلة**.

## 2. الرحلة من السكربت للقصة المنشورة

```
script.json + cast.json + intake.json        ← جايين من الموديولات 1-5
        │
S6  الصوت           كل جملة ← صوت MP3 + توقيت كل كلمة
S7  المخرج           الذكاء بيقرر مين واقف وين وشو بيتحرك وإمتى (JSON بس)، والكود بيفحص
S8  الرسّام           الكود بيرسم المشهد SVG من الخطة + مكتبة الرسومات
S9  الجدول الزمني     أوقات حقيقية لكل جملة وكلمة وحركة وفعالية
S10 المجمّع          index.html واحد: الرسومات + البيانات + المشغّل + الخط
        │
S11 الفاحص           بيفتح القصة بـ Chromium على 3 شاشات وبيفحص كل شي
        │             فيه غلط؟ ← بيرجع للمرحلة المسؤولة (S7 أو S8 أو S5) ويعيد
S12 النشر            published أو needs_review + webhook
        │
Review               تعليقات ← مخطط التعديل ← نسخة جديدة بس للمشاهد اللي تغيّرت
```

**أهم قاعدة بالمشروع كله (نص الخطة):** الذكاء الاصطناعي **ما بيكتب كود ولا CSS ولا SVG للصفحة أبداً**. بيعبّي JSON، والكود تبعنا بيفحصه، والمشغّل تبعنا بيحرّكه. هيك ما في طريقة يدخل كود غريب على الصفحة.

## 3. كيف تجرّبه (على ويندوز)

### مرة وحدة: التجهيز

```bat

pip install -e ".[dev]"
python -m playwright install chromium
python scripts\fetch_fonts.py
```

- لازم يكون عندك **Python 3.11 أو أحدث** و**ffmpeg** (`conda install -c conda-forge ffmpeg` أو `winget install ffmpeg`، وتأكد بـ `ffmpeg -version`).

- `fetch_fonts.py` بنزّل خط Cairo. بدونه القصة بتشتغل بخط بديل ورح يطلع `FONT_FALLBACK`.

### ابنِ القصة وشغّلها

```bat

python scripts\serve_bundle.py out\golden
```

## 4. S6 — الصوت (`pipeline/stages/s6_audio.py`)

**بياخد:** السكربت + الشخصيات + intake (اللغة واللهجة) + قائمة الأصوات `config/voices.yaml`.
**بيطلّع:** `audio.json` + ملف MP3 لكل جملة.

### الخطوات لكل جملة (نص الخطة)

1. **`assign_voices`** — صوت لكل شخصية بنفس الجنس والعمر واللهجة. إذا خلصت الأصوات: الأقل استعمالاً مع تغيير طبقته ±2.
2. **`split_text`** — الجملة الأطول من حد المزوّد (Groq: 200 حرف) بتنقسم عند نهايات الجمل وبتنلزق مع 120ms سكوت.
3. **`audio_tools.to_mp3`** — ffmpeg: قص السكوت، علو صوت −16 LUFS، MP3 أحادي 24kHz 96kbps.
4. **الرحلة العكسية** — الصوت بيرجع لـ STT، وبنقارن اللي انسمع مع اللي لازم ينحكى (WER). أكتر من 25% غلط ← إعادة مرتين.
5. **`align_words`** — توقيت كل كلمة **من النص المعروض**. "1/4" بتاخد مدة "واحد من أربعة" كلها.

### الفحوصات (نص الخطة)

| الفحص | الدرجة |
| --- | --- |
| الملف MP3 أحادي 24kHz | blocker |
| المدة بين 0.5 و 25 ثانية | blocker |
| مش ساكت (أعلى من −35 dB) | blocker |
| سرعة الكلام بين 1.2 و 4 كلمات/ثانية | major |
| WER لحد 0.25 تمام، لحد 0.35 minor، أكتر major | minor / major |

### اجتهاد

- **أصوات Groq كلها "بالغ"** لأنه Groq ما بيعطي أعمار.
- **الصوت التجريبي صار همهمة ناعمة** بدل "الطن طن": نغمة 120–230 هيرتز بتطلع وتنزل بنعومة. لسا مش كلام حقيقي، بس مش مزعجة.
- **أي فشل بجملة = blocker مش انهيار**: صوت ساكت، نص فاضي، أو ffmpeg فشل ← blocker لهاي الجملة، والجمل الباقية بتكمّل.
- **الصوت بيتخزن لكل نسخة لحال** (`stories/{id}/v{n}/audio/…`).
- **`measured_wps`** — دالة بتحسب سرعة الكلام الحقيقية للقصة كلها، عشان المعايرة (9.7).

## 5. S7 — المخرج (`pipeline/stages/s7_director.py`)

**بياخد:** مشهد واحد (جمله + مدده الحقيقية + توقيت كل كلمة) + الشخصيات + المكان + الكتالوج.
**بيطلّع:** `scene_plan.json` — مين واقف وين، الأغراض، وقائمة cues (حركات بأوقات).

الذكاء بيكتب الخطة (تعليماته بـ `pipeline/prompts/s7_director.md`)، و**الكود بيفحصها** بـ `validate_s7`. أي قاعدة مكسورة ← الخطة بترجع للذكاء مع الغلطات (لحد 3 محاولات).

### أنواع الـ cues

- **حركات:** show, hide, fade, move, scale, rotate, keyframes, highlight, shake, camera, enter, exit
- **حالات:** pose، expression، face
- كل cue مربوط بجملة: بأولها، بآخرها، أو **عند كلمة معيّنة**.

### القواعد (نص الخطة، كلها blocker)

1. اللي بحكي لازم يكون على المسرح، أو يدخل قبل أول جملة إله.
2. أكتر شي 4 شخصيات و12 غرض/ويدجت.
3. **تغيير مرئي كل 6 ثواني على الأقل.**
4. كل شي جوّا المسرح (x من 40 لـ 1240، y من 40 لـ 700) إلا اللي داخل/طالع.
5. الشخصيات ما بتتداخل أكتر من 35%.
6. الكاميرا: حركتين بالأكتر، زوم بين 1.0 و 1.4.
7. نص الويدجت: 4 كلمات بالأكتر و44 بكسل على الأقل.
8. كل `ref` وهدف وجملة وكلمة موجود، وكل باراميتر صح.
9. `tap_reveal`: كل هدف حجمه 64×64 على الأقل.

### اجتهاد (قواعد زيادة، طلعت من الفحص الشامل)

- **"تغيير كل 6 ثواني" = تغيير حقيقي بس**: cue بيحط نفس القيمة الموجودة ما بينحسب.
- **`offstage_ok` مش ثغرة**: بيرخّي هامش الـ 40 بكسل بس، وبس لشخصية إلها `enter` أو `exit`. غير هيك واحد ممكن يحكي وهو مش باين (`OFFSTAGE_NO_CUE`).
- **وين بتنتهي الحركة لازم يكون جوّا المسرح** (`move` و `keyframes`).
- **الكاميرا ما بتفرجي برّا المسرح** بأي زوم (`CAMERA_BOUNDS`).
- **حركتين على نفس الخاصية بنفس الوقت ممنوع** (`TWEEN_OVERLAP`): التانية بتمسح الأولى والعنصر بنط.
- **باراميترات الويدجت بتنفحص برسمها فعلاً**، مش بس بالشكل.
- **لما نعيد مشهد** (تصليح أو تعديل) المخرج بيشوف خطته الحالية (`<current_plan>`) مع شو لازم يتغيّر، فبغيّر بس اللازم.
- **أي نص داخل للذكاء بيتهرّب** عشان ما يقدر يسكّر الوسم ويكتب تعليمات.

## 6. S8 — الرسّام (`pipeline/stages/s8_composer.py`)

**بياخد:** خطة المشهد + الشخصيات + الكتالوج.
**بيطلّع:** `scene.svg` + `scene_meta.json` (مربع كل عنصر).

### شكل المشهد

```
<g id="scene-s03" class="scene-root tod-evening">      وقت اليوم بيغيّر ألوان السما والأرض
  <g id="camera">
    <g class="bg">…الخلفية…</g>
    <g id="table1" class="el prop">                     هون بتشتغل الحركات
      <g transform="…المكان المخطط…">…الرسمة…</g>      هون المكان الثابت
    </g>
    <g id="nadia" class="actor" data-pose data-expr data-facing>…</g>
  </g>
</g>
```

**ليش طبقتين لكل عنصر؟** الحركة على الخارجية والمكان على الداخلية، فالحركة دايماً **نسبة لمكانه**.

### الدوال

| الدالة | شو بتعمل |
| --- | --- |
| `compose(plan, cast, catalog)` | بتبني الـ SVG مرتب حسب z |
| `check_scene_svg(svg)` | السانيتايزر + ids مش مكررة + ما في ألوان خام |
| `make_custom_prop(...)` | غرض مش بالمكتبة (قطّاعة البيتزا): الذكاء بيرسمه، السانيتايزر بيفحصه، نموذج رؤية بيعطيه علامة (لازم 4+ من 5). فشل 3 مرات ← صندوق عام + `CUSTOM_PROP_FALLBACK` |

### اجتهاد

- **نموذج الرؤية لازم يشوف صورة فعلاً**: `pipeline/render.py` بيرسم الغرض بـ Chromium ويبعته صورة. بدون صورة ← صندوق عام. (قبل كان ممكن ينقبل بدون ما ينشاف.)
- **الرسمة بتنحفظ للقصة** (`custom_props`)، فلما نعيد مشهد ما بنرسم الغرض من جديد.
- **فحص الألوان على قيم الخصائص بس**: "Room #101" على لافتة مش لون.
- **عمق التداخل 12 بالضبط**: دمجت التحويلات، وصار جذر المشهد هو نفسه الـ `<svg>`.

## 7. S9 — الجدول الزمني (`pipeline/stages/s9_timeline.py`)

## 8. S10 — المجمّع (`pipeline/stages/s10_assembler.py`)

**بيطلّع:** `index.html` + `audio/*.mp3` + `meta.json`.

### الخطوات (نص الخطة)

1. **`namespace_scene`** — كل id بصير `s03-nadia` عشان ما يتكرر بين المشاهد.
2. **`subset_font`** — بس الحروف المستعملة من Cairo، جوّا الصفحة.

4. **`check_bundle`** (8.6): الصفحة ≤ 1.5MB، الصوت ≤ 8MB، ولا رابط خارجي، بالضبط 2 `<script>`، ولا `onclick=`، ids مش مكررة، story-data مطابقة، كل صوت وهدف موجود.

### الحماية من النص الخبيث (نص الخطة 8.7)

### اجتهاد (من الفحص الشامل)

- **القالب بيتعبّى بمرة وحدة**: لو قصة فيها `{{player}}` بتضل نص، ما بتصير كود.

- **السانيتايزر صار يمسك**: `<?…?>` و CDATA وأي `\` بقيمة (`u\72l(` هي طريقة مخفية لكتابة `url(`).
- **بدون html5lib** بيطلع minor `HTML_PARSE_UNCHECKED` بدل ما يسكت. عندك بعد `pip install` الفحص بيشتغل.

## 9. المشغّل (`runtime/player.js`)

JavaScript عادي بدون مكتبات (الحد 60KB).

### الفكرة: ساعة وحدة (نص الخطة 7.5)

- **ساعة وحدة `T`** وكل شي بيمشي عليها. كل حركة Web Animation **واقفة**، وبكل فريم وقتها = `T − بدايتها`. القفز لأي ثانية بيحط كل شي بمكانه.
- **الحالات**: آخر cue قبل `T`. **الفم**: بيفتح ويسكّر جوّا الكلمات. **الكابشن**: الكلمة الحالية مظللة.

### الفعاليات (نص الخطة 7.7)

| النوع | شو بيصير |
| --- | --- |
| `tap_reveal` | دواير حوالين الأغراض، ضغطة ← فقاعة شرح |
| `choose_answer` | الغلط بيتعطّل ومعه الشرح، محاولتين |
| `drag_match` | سحب وإفلات، أو ضغطة وضغطة |
| `predict` | أي جواب، وبعدين الشرح |

**تخطي** بعد 8 ثواني، **تلميح** إذا في، **متابعة** بعد ما يخلص.

### أدوات الفحص `window.__story` (نص الخطة 7.10)

`seek`, `play`, `pause`, `getState`, `getFrameInfo`, `listInteractions`, `openInteraction`, `answerInteraction`… S11 بيتحكم بالقصة فيها. `?freeze=1` بيوقف التنفس والرمش للصور.

### اجتهاد (أغلبه من الفحص الشامل)

- **أول كلمة ما بتنقص**: الساعة بتستنى (ثانيتين بالأكتر) لحد ما صوت الجملة يبلش، والجملتين الجايات بيتحمّلوا مسبقاً.
- **الكابشن الطويل بيصغر فعلاً لـ 16 بكسل** قبل ما ينقص لسطرين، وبيعيد يقيس لما الشاشة تتغيّر.
- **دواير tap_reveal بمكان الغرض الحقيقي** (بعد حركته والكاميرا)، 44 بكسل على الأقل، والكرت بيروح للنص التاني من الشاشة.
- **متابعة وتخطي بيكمّلوا التشغيل** وبيرجعوا الفوكس لزر التشغيل. Tab ما بيطلع من الكرت.
- **الاختصارات ما بتشتغل مع Ctrl/Cmd/Alt**، وتلميح "لف التلفون" بيطلع مرة وحدة.
- **وضعية الحكي صارت أحيا**: الإيد بتتحرك بمفصلين والراس بيهز شوي.
- **قفزة فاشلة مش "انحراف"**: الصوت أبعد من ثانية عن الساعة = سيرفر بدون Range.

## 10. S11 — الفاحص (`pipeline/stages/s11_validate.py` + `s11_repair.py`)

- **حالة الخطة "الصوت متأخر 400ms" ما بتفشل**: المشغّل بيلحق الصوت عن قصد، فهاد مش غلط.

## 11. S12 — النشر (`pipeline/stages/s12_publish.py`)

### نص الخطة

| الحالة | شو بيصير |
| --- | --- |
| ما في blocker ولا major | `published` + ذاكرة الفكرة + webhook `story.published` |
| نسخة جديدة فوق منشورة | القديمة `superseded` |

| --- | --- |
| `run` | بتنشر أو بتحط `needs_review` |
| `approve` | بتنشر نسخة `needs_review`، **مرفوضة إذا في blocker** |
| `rollback` | بترجع لنسخة `published` أو `superseded`، مش `failed` |

- **`approve` بيعمل كل شي بعد النشر** (ذاكرة الفكرة والتعليقات)، زي النشر العادي.
- **`MemoryVersionStore`** مخزن بالذاكرة للفحوصات. الداتابيز الحقيقية شغل M0، بنفس الواجهة `VersionStore`.

## 12. Review — التعليقات والتعديل (`pipeline/review/`)

### نص الخطة (10.1–10.3)

1. **تعليق** (`comments.py`): 1–1000 حرف. إذا في وقت بس (`t_ms`) بنعرف المشهد منه. بيتسجّل `open` وبيتجدول تعديل بعد **30 ثانية**.
2. **لما يبلش التعديل**: كل التعليقات المفتوحة بتصير `batched` وبتنحل مع بعض.
3. **مخطط التعديل** (`planner.py`): الذكاء بيرجع `patches` بنوع: `lines`، `visual`، `audio`، `interaction`، `cast`. وبيرفض تعليق بسبب (مثلاً بيشيل مفهوم أساسي).
4. **التنفيذ** (`revision.py`): بس اللازم. `visual` ← S7 لهاد المشهد بس. `lines` ← S4 تعديل + S6 للجمل اللي تغيّرت + S7–S10. الباقي بيتعاد استعماله.
5. **فحص** + S11 للمشاهد اللي تغيّرت. نجح ← نشر تلقائي (أو `needs_review` إذا `REVISION_REQUIRES_APPROVAL`). التعليقات ← `applied`.

### اجتهاد (طلع من الفحص الشامل)

- **القصة ما بتعلق "مشغولة" للأبد**: مرحلة خلصت محاولاتها ← blocker `VALIDATION_EXHAUSTED`. أي غلط تاني ← النسخة `failed` والتعليقات بترجع مفتوحة.
- **قصة مشغولة** ← التعديل بيستنى والتعليقات بتضل مفتوحة (ما بتضيع).
- **المخطط فشل** ← التعليقات بترجع مفتوحة وبتتجدول من جديد.
- **تعديل `lines` بيعيد صوت كل جملة تغيّر نصها**، مش بس اللي المخطط ذكرها.
- **التعليقات بتصير `applied` بس لما النسخة تنتشر** (بالنشر أو بـ `approve`).

### قبول المكتبة (نص الخطة 6.8) — `devtools/library.py`

- **صفحات صور**: الخلفيات بكل أوقاتها، الأغراض، و**12 شخصية عشوائية × 6 تعابير × 10 وضعيات**.
- **نموذج رؤية بيقيّم كل صفحة** (لازم 4+). `review_sheets` جاهزة، بتستنى عميل الرؤية الحقيقي (M1).
- **فحص المفاصل**: بكل وضعية وكل عمر، الإيدين والرجلين لازقين بالجسم.

### قواعد الرسم

- **كل لون متغيّر CSS** — ولا لون hex. نفس الرسمة بتتلوّن حسب العمر والوقت.
- **العمر** (طفل/مراهق/بالغ/كبير) بالـ CSS، مش رسمة منفصلة.
- **الويدجتس بالكود**: `render_widget("widget_pie_fraction", {"parts": 4, "filled": 1})`.

### اجتهاد

- **الويدجت على كرت ورقي** عشان ما يختلط بالخلفية.
- **ما في ليل** للمدرسة والسوق والصف (ما حدا هناك بالليل).
- **الويدجت بيكتب الأرقام** حسب إعداد الأرقام (عربية أو غربية).

### التحسينات الجديدة (اجتهاد، طلبتها إنت، مش بالخطة)

- **ظل تحت الشخصيات والأغراض:** صاروا واقفين على الأرض بدل ما يبينوا طايرين. الأغراض اللي على الحيط (الشمس، الشباك، ساعة الحيط…) بدون ظل.
- **خدود للوجوه:** لون وردي خفيف بيعطي الشخصية حياة.
- **فرن المطبخ انتقل للطرف:** الطاولة بنص المشهد ما عادت قدّامه.
- **5 أغراض جديدة:** مرشة ماء، نبتة بجذورها، بطاقة سعر، حذاء رياضي، منبّه.
- **كل غرض إله اسم عربي** (`data-label-ar`).

### الأماكن الحيّة (اجتهاد، بنفس قاعدة الخطة لحركات الراحة)

- **الساعات:** عقرب الساعة بيمشي (ساعة الحيط، المنبّه، ساعة المدرسة).
- **الطبيعة:** الشمس بتلف ببطء، الورد والنبات والشجر بيتمايل، الغيم بيمشي، النجوم بتلمع بالليل.
- **المطبخ:** بخار من الطنجرة والكاسة، وضو الفرن شغّال.
- **الأماكن العامة:** عصافير بتطير بالسما، وقطط قاعدة بذيل بيتحرك وعيون بترمش (الشارع، الحديقة، السوق، ساحة المدرسة، الملعب). وفي قطة بالمكتبة كمان (`prop_cat`).
- **نص الخطة اللي مشينا عليه:** حركات الراحة (التنفس والرمش) CSS بس، ما بتنقفز، بتوقف بـ `freeze=1` وبـ "حركة أقل"، وما بتنحسب كتغيير بالمشهد. الأماكن الحيّة ماشية على نفس القاعدة بالضبط، وبتوقف بالمشاهد اللي مش ظاهرة.
- **الأداء:** S11 صار يقيس سرعة الصفحة والحركات شغّالة: حوالي 60 فريم بالثانية حتى على جهاز بطيء.

### التفاعل الخفيف (اجتهاد، إضافة على الخطة)

- **تضغط على شخصية:** بتأشّر بإيدها وبتنبسط، وبيطلع اسمها.
- **تضغط على غرض:** بينط شوي، وبيطلع اسمه ("طاولة"، "بيتزا"…).
- **ما بيوقف القصة أبداً**، وما بيشتغل وفي سؤال مفتوح، ومش محسوب من الأسئلة (من 2 لـ 4، نص الخطة ما تغيّر).
- إذا المهندس رفض الفكرة، بتنشال من مكان واحد بالمشغّل.
