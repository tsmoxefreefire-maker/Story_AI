# الـ API تبع الموديول 6 (FastAPI)

> **خطة** = مكتوب بالـ spec (`00_shared.md`). **اجتهاد** = قرار مني مش مكتوب بالخطة.
> كل كود الـ API ملفات جديدة، وما تغيّر ولا ملف من كود الموديول 6 القديم. كل المتغيرات مكتوبة كمان بـ `.env.example`.

---

## 1. الفكرة

- طبقة FastAPI فوق الموديول 6: بتستقبل القصة، وبتبنيها بالخلفية (S6 لـ S10)، وبعدين S12 بينشرها، وبتعطيك رابط تشغيل.
- القصة بتوصل من 3 أماكن، وكلهم بيمشوا بنفس الطريق جوّا الموديول 6:
  1. **قصة جاهزة** من مجلد `stories/` (النبات، الساعة، النسبة).
  2. **قصة ملصوقة كـ JSON** بالصفحة أو بـ `/v1/dev/stories/json`.
  3. **من الموديولات 1–5** عن طريق `POST /v1/stories`، لما ينوصلوا (نقطة الربط جاهزة).
- **خطة:** العقد بـ §3، المتغيرات بـ §11.1، واجهة الـ LLM بـ §11.2، الحدود بـ §11.3، الأخطاء والمحاولات بـ §12.
- **اجتهاد:** الـ API وفيشة الذكاء بالأصل شغل مشترك (M0 و M1 و M7 و M8). بنيناهم هون لأنك طلبت إنه الشغل يكون كامل ومع بعض، وكله FastAPI.

## 2. صفحة التجربة (اجتهاد)

افتح رابط السيرفر نفسه (`https://اسم-خدمتك.onrender.com`)، بدون `/docs`.

1. **المفتاح:** بتحط قيمة `API_KEYS` مرة وحدة، وبتنحفظ بالمتصفح تبعك بس (مش بالكود ولا على GitHub).
2. **أوتوماتيك:** بعدها الصفحة بتشغّل آخر قصة جاهزة، أو بتبني قصة النبات لحالها إذا ما في ولا وحدة.
3. **قصة ثانية:** كبسة على كرتها.
4. **الصق قصة:** مربع بتلصق فيه `intake` و `script` و `cast`، وهاد نفس اللي رح يجي من الموديولات 1–5.
   - زر **عبّي مثال** بيعبّيلك المربع بقصة جاهزة، فبتقدر تغيّر الأسماء والجمل وتجرّب.
   - **بدون خطط المشاهد:** إذا الذكاء موصول، المخرج (S7) بيكتب الخطط لحاله. إذا مش موصول، الصفحة بتحكيلك فوراً شو ناقص.
5. **الأخطاء:** الصفحة بتكتب السبب، وفيها زر **انسخ التفاصيل** عشان تبعته لـ Claude.

فوق بالصفحة مكتوب حالة السيرفر: ffmpeg ✓ أو ✗، والذكاء ✓ أو ✗.

## 3. فيشة الذكاء للمخرج (S7)

**شو بتعمل:** المخرج بيكتب خطة كل مشهد (مين وين وشو بيعمل وعند أي كلمة). العقل نفسه (التعليمات، والفحص، و3 محاولات) كان مبني. الناقص كان بس الفيشة اللي بتتصل بموديل حقيقي، وهاي هي `providers/llm/clients.py`.

**كيف بتشتغل (§11.2 و §14):**

1. بتطلب من الموديل JSON بس، وبتورجيه الشكل المطلوب (JSON Schema).
2. بتفحص الجواب. إذا مش JSON أو شكله غلط، بتعطي الموديل **محاولة تصليح وحدة** مع الأغلاط.
3. إذا لسا ما زبط، بترجع جواب فاضي، والمخرج بيعدّها محاولة فاشلة وبيعيد مع الملاحظات (لحد 3).
4. الأخطاء المؤقتة (429، 5xx، انقطاع) بتنعاد لحد 5 مرات، وبتستنى المدة اللي بيطلبها المزوّد.
5. أي رفض ثاني (مفتاح غلط، موديل مش موجود) بيخلي النسخة `failed` بكود `PROVIDER_ERROR`، والرسالة ما فيها المفتاح أبداً.

**كيف توصلها على Render** (Environment ← Add Environment Variable). المفتاح بيتحط هون بس:

| المزوّد | المتغيرات |
| --- | --- |
| **Groq** | `LLM_PROVIDER=openai_compatible`، `OPENAI_BASE_URL=https://api.groq.com/openai/v1`، `OPENAI_API_KEY=` مفتاح Groq، `LLM_MODEL_LARGE=openai/gpt-oss-120b` |
| **Gemini** | `LLM_PROVIDER=openai_compatible`، `OPENAI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai`، `OPENAI_API_KEY=` مفتاح Gemini، `LLM_MODEL_LARGE=` اسم موديل Gemini |
| **Claude** | `LLM_PROVIDER=anthropic`، `ANTHROPIC_API_KEY=` المفتاح (الموديلات الافتراضية من الخطة) |
| **أي مزوّد ثاني بنفس شكل OpenAI** | نفس سطر Groq، بس غيّر الرابط واسم الموديل |

- `LLM_MODEL_VISION` اختياري: موديل بيشوف صور، عشان يحكم على الرسمات الخاصة (S8). بدونه، أي غرض مش بالمكتبة بيصير صندوق عام، وبيطلع تحذير `CUSTOM_PROP_FALLBACK`.
- بدون أي مفتاح، كل إشي بيضل شغّال زي قبل، بس على القصص اللي فيها خطط جاهزة.
- **تنبيه عن Groq المجاني:** حدّ الموديل `openai/gpt-oss-120b` المجاني 8 آلاف توكن بالدقيقة و200 ألف باليوم. طلب المخرج لمشهد واحد حوالي 6 آلاف توكن، غير الجواب. فممكن يعلق أو يبطّئ، وقصتين تقريباً بتخلّص حد اليوم. إذا صار هيك، الصفحة بتكتب `PROVIDER_ERROR`، والحل مزوّد أو باقة حدودها أوسع.
- **لازم تعرف:** جربت الفيشة بموديل وهمي، وبنت القصة كاملة (المخرج كتب الخمس مشاهد). بس **ما جربتها على موديل حقيقي**، لأنه ما عندي مفتاح ولا نت للمزوّدين. أول تجربة حقيقية رح تكون عندك.

## 4. نقطة الربط مع الموديولات 1–5

**نص الخطة:** `POST /v1/stories` بياخذ موضوع الدرس وبيرجّع 202، والموديولات 1–5 بتحوّله لسكربت وشخصيات، والموديول 6 بيكمّل.

**شو جاهز:** `api/upstream.py` فيه الباب الوحيد اللي بيدخلوا منه:

```python
class MyModules:
    def run(self, request: dict) -> dict:
        # request = body تبع POST /v1/stories
        return {"intake": {...}, "script": {...}, "cast": {...}}  # و "plans" اختياري
```

- إذا رفضوا الطلب بكود من الخطة (`INPUT_TOO_SHORT`، `TOPIC_NOT_FOUND`…)، بيرموا `UpstreamError(code, message)`، والنسخة بتصير `failed` بنفس الكود.
- **لما يجي كودهم:** بنكتب كلاس زي اللي فوق بينادي شغلهم، وبنحط اسمه بمتغير `STORY_UPSTREAM` على Render (مثلاً `team.modules:MyModules`). بدون ما نغيّر سطر بالموديول 6.
- لحد هلّق `POST /v1/stories` بيرجّع 501 `NOT_CONNECTED`. التكرار محسوب حسب المفتاح الطبيعي اللي بالخطة، و `Idempotency-Key` بيحل محله.
- جربتها بموديولات وهمية: الطلب راح، رجعت القصة، والموديول 6 بناها ونشرها.

## 5. التشغيل على جهازك (PyCharm، PowerShell)

```powershell
pip install -r requirements.txt
$env:API_KEYS = "dev-key-123"
python scripts/run_api.py
```

افتح `http://localhost:8000` (صفحة التجربة) أو `http://localhost:8000/docs`.

- `dev-key-123` مفتاح تجربة على جهازك بس.
- إذا ما حطيت `PLAY_TOKEN_SECRET`، السكربت بيعمل واحد عشوائي لهاي التشغيلة بس.

**الفحوصات:**

```powershell
pytest tests\unit\test_api_core.py tests\unit\test_api_inputs.py tests\unit\test_llm_clients.py tests\unit\test_api_routes.py
```

- أول ثلاث ملفات نجحوا كلهم عندي.
- `test_api_routes.py` بيمرّ على الـ routes بـ FastAPI TestClient. **ما قدرت أشغّله عندي** (ما في نت لتنزيل FastAPI)، وبيشتغل عندك. على Render اشتغل فعلياً `/v1/health` و `/docs` وبناء قصة وفحص حالتها، بس لسا ما شفنا قصة منشورة هناك.

## 6. الـ endpoints

| الطلب | شو بيعمل | المصدر |
| --- | --- | --- |
| `POST /v1/stories` | موضوع درس ← الموديولات 1–5 ← الموديول 6. 202، أو 200 لنفس الطلب. 501 لحد ما ينوصلوا | خطة (والـ 501 اجتهاد) |
| `POST /v1/dev/stories` | بيبني مجلد قصة جاهز من `stories/` | اجتهاد |
| `POST /v1/dev/stories/json` | بيبني قصة ملصوقة: `{"story": {intake, script, cast, plans?}}` | اجتهاد |
| `GET /v1/dev/folders` | أسماء القصص الجاهزة | اجتهاد |
| `GET /v1/dev/folders/{folder}/json` | قصة جاهزة كـ JSON واحد، كمثال للصق | اجتهاد |
| `GET /v1/stories/{id}` | الحالة والتقدّم والنتيجة والمشاكل | خطة |
| `GET /v1/stories` | قائمة، مع فلاتر `lesson_id` و `topic_id` و `book_id` و `status` و `limit` و `cursor` | خطة |
| `POST /v1/stories/{id}/access-link` | رابط تشغيل موقّع، 6 ساعات افتراضياً وأقصاه 24 | خطة |
| `GET /v1/play/{token}/index.html` | القصة. بدون مفتاح، ومع هيدرات الحماية بالحرف | خطة |
| `GET /v1/play/{token}/audio/{file}` | ملف صوت، مع `Range` | الملف خطة، والـ Range اجتهاد |
| `GET /v1/stories/{id}/package` | ZIP للاستخدام بدون نت | خطة |
| `POST /v1/stories/{id}/comments` | تعليق مراجع، بيستنى `open` | خطة |
| `POST /v1/stories/{id}/versions/{n}/approve` | بينشر نسخة `needs_review`. بيرفض إذا فيها blocker | خطة |
| `POST /v1/stories/{id}/rollback` | بيرجّع نسخة قديمة | خطة |
| `POST /v1/stories/{id}/regenerate` | نسخة جديدة. قصة من الموديولات 1–5 بترجع تمرّ عليهم من الأول | خطة |
| `GET /v1/health` | التخزين، و ffmpeg، والذكاء (`llm`)، والموديولات 1–5 (`upstream`). بدون مفتاح | خطة (+ llm و upstream اجتهاد) |
| `GET /` | صفحة التجربة | اجتهاد |

كل الطلبات تحت `/v1` بدها `X-API-Key`، إلا `/v1/play/...` و `/v1/health`.

## 7. الملفات: كل ملف وشو بيستخدم

| الملف | شو فيه | بيستخدم |
| --- | --- | --- |
| `providers/llm/clients.py` | فيشة الذكاء: `AnthropicClient` و `OpenAICompatibleClient` و `from_env()` | Python عادي + httpx، **LLM** |
| `api/upstream.py` | نقطة الربط مع الموديولات 1–5: `Upstream` و `UpstreamError` و `load_upstream` | Python عادي |
| `api/service.py` | `StoryService`: الشغل كله، من استقبال القصة لحد النشر والمراجعة | Python عادي + الموديول 6 |
| `api/app.py` | `create_app()`: بتجمع الإعدادات والذكاء والموديولات 1–5 والـ routes والأخطاء و `/v1/health` | FastAPI |
| `api/routes_stories.py` | routes القصص والـ dev | FastAPI |
| `api/routes_play.py` | التشغيل والصوت | FastAPI |
| `api/routes_try.py` | الرابط `/` لصفحة التجربة | FastAPI |
| `api/try_page.py` + `try_page.html` | الصفحة نفسها، وأسماء القصص اللي بتنكتب فيها | Python عادي + HTML/JS |
| `api/auth.py` | فحص المفتاح وحد الطلبات | FastAPI (`APIKeyHeader`) |
| `api/schemas.py` | شكل كل body | Pydantic |
| `api/tokens.py` | توقيع رابط التشغيل وفحصه | Python عادي (HMAC-SHA256) |
| `api/headers.py` | هيدرات الحماية والـ Range | Python عادي |
| `api/limits.py` | حد الطلبات بالدقيقة وحد الـ 1 MB | Python عادي (ASGI) |
| `api/settings.py` | إعدادات الـ API من متغيرات البيئة | Python عادي |
| `api/errors.py` | شكل الخطأ | Python عادي |

**كيف بتمشي القصة جوّا `service.py`:**

1. القصة بتنعمل، ونسختها الأولى `queued`. نفس الطلب مرة ثانية بيرجّع نفس القصة.
2. `run_version` بالخلفية: إذا القصة من `POST /v1/stories`، بتمرّ أول إشي على الموديولات 1–5. بعدين S6 لـ S10 (والمخرج بيستخدم الذكاء للمشاهد اللي ما إلها خطة)، وبعدين S12.
3. مرحلة خلصت محاولاتها: `needs_review` مع مشاكلها و `VALIDATION_EXHAUSTED`، وما بتنفع تنوافق لأنه ما في قصة كاملة.
4. المزوّد رفض أو ضل مشغول: `failed` بـ `PROVIDER_ERROR`. خطأ بالكود: `failed` بـ `INTERNAL`. وما في نسخة بتضل `running` أبداً.

## 8. أكواد الأخطاء

| الكود | وين | متى | المصدر |
| --- | --- | --- | --- |
| `UNAUTHORIZED` | HTTP 401 | مفتاح ناقص أو غلط، أو token تشغيل مزوّر أو منتهي | خطة |
| `INPUT_INVALID` | HTTP 422 | body غلط، قصة ملصوقة ناقصة، خطط ناقصة بدون ذكاء، body أكبر من 1 MB | خطة |
| `INPUT_INVALID` | HTTP 416 | `Range` برّا ملف الصوت | اجتهاد |
| `NOT_FOUND` | HTTP 404 | قصة أو نسخة أو ملف مش موجود، أو قصة لسا مش منشورة | خطة |
| `STORY_BUSY` | HTTP 409 | في نسخة `queued` أو `running` | خطة |
| `RATE_LIMITED` | HTTP 429 | أكثر من `RATE_LIMIT_RPM` طلب بالدقيقة (الافتراضي 120) | خطة |
| `INVALID_VERSION_STATE` | HTTP 409 | approve أو rollback لنسخة ما بتنفع | اجتهاد |
| `NOT_CONNECTED` | HTTP 501 | `POST /v1/stories` قبل ما تنوصل الموديولات 1–5 | اجتهاد |
| `INTERNAL` | HTTP 500 / نسخة `failed` | خطأ بالكود | خطة |
| `PROVIDER_ERROR` | نسخة `failed` | مزوّد الذكاء رفض (مفتاح، موديل) أو ضل مشغول بعد 5 محاولات | خطة |
| `VALIDATION_EXHAUSTED` | نسخة `needs_review` | مرحلة خلصت محاولاتها | خطة |
| `INPUT_TOO_SHORT`، `TOPIC_NOT_FOUND`… | نسخة `failed` | الموديولات 1–5 رفضت الطلب | خطة |

## 9. قرارات (اجتهاد)

1. **التخزين بالذاكرة** لحد ما تجهز قاعدة البيانات (M0). لما يطفي السيرفر بتروح القصص.
2. **القصص الجاهزة والملصوقة** بدائل مؤقتة للموديولات 1–5، وبيمشوا بنفس طريقهم بالضبط.
3. **كل قصة ملصوقة إلها مجلد باسم محتواها:** نفس القصة مرتين بتاخذ نفس المجلد، وقصة ثانية ما بتقدر تغيّر مدخلات قصة موجودة.
4. **جواب الذكاء اللي ما بنفع بعد التصليح** بيرجع فاضي، والمخرج بيعيد بملاحظاته بدل ما توقف النسخة كلها.
5. **موديل يشوف صور اختياري:** بدونه، الرسمة الخاصة ما بتنحكم وبتصير صندوق عام، عشان ما توصل رسمة ما حدا شافها للقصة.
6. **Range للصوت، وحد الطلبات وحد الـ 1 MB بالذاكرة، ومقارنة المفاتيح بالـ bytes، وزر Authorize بـ `/docs`:** زي ما كانوا.

## 10. شو لسا ناقص

- **كود الموديولات 1–5:** شغل الفريق. أول ما يجي، بنوصله بـ `STORY_UPSTREAM`.
- **تجربة الذكاء على موديل حقيقي:** بدها مفتاح عندك على Render.
- **قاعدة البيانات** (M0)، **إرسال الـ webhooks** (M7)، و **S3**.
- **التعليق يعمل تعديل لحاله:** المخطِّط (`pipeline/review/planner.py`) جاهز ويستخدم نفس الفيشة، بس الـ API لسا ما بيشغّله. بنضيفه لما تطلب.
- **`media-src`:** `'self'` اشتغل على Chromium، و Safari لسا لازم يتجرب.
