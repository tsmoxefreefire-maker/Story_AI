### S5 Cast and Setting (large LLM plus code)

Input: the script, the localization brief, `assets/catalog.json` (the allowed parameter values) and the age group. Output `cast.json`:

- `characters[]`: `key` (from the script), `build` (`child`, `teen`, `adult`, `elder`), `presentation` (`f` or `m`), `skin_tone` (0 to 5), `hair_style` (catalog id), `hair_color` (0 to 5), `top` and `bottom` (`{style, color_token}`), `shoes` (id), `accessories[]` (ids), `head_covering` (`none`, `hijab`, `cap`, `kufi`), `voice_profile` (`{gender, age_band, energy}`), `idle_style` (`calm`, `normal`, `lively`).
- `settings[]`, one per scene: `scene_id`, `background_id`, `time_of_day` (`day`, `evening`, `night`), `prop_ids[]` (catalog ids), `custom_props[]` (`{key, description}` with at most 20 words, at most 2 per scene).

Rules: choose only catalog ids and listed values. `build` follows `age_years` (up to 11 child, 12 to 17 teen, 18 to 59 adult, 60 and above elder). Presentation follows the script’s `gender`. Outfits and head coverings follow the brief’s `clothing_norms` and the scene’s setting. Two characters in the same scene must differ in at least two of: skin tone, hair style or color, top color. A character keeps an identical design in every scene. Colors come from palette tokens (Section 6).

Validation: code checks catalog references, the distinctness rule, a setting for every scene, and that the background supports the time of day (blockers). A small LLM review flags stereotyping or caricature; a flag is a blocker.

### 6.3 Character kit

`assets/characters/build_character.py` composes one `<g>` per character from `assets/characters/parts/*.svg` and the character’s parameters. Local coordinates: viewBox 0 0 200 400, feet on y = 390, ground contact at (100, 390).

**Required part group ids:** `head`, `hair-back`, `hair-front`, `face`, `eyes`, `brows`, `mouth`, `neck`, `torso`, `arm-l`, `arm-r`, `leg-l`, `leg-r`, `shoes-l`, `shoes-r`, `head-covering`, and `accessory-<id>` for each accessory.

**Pivots** (transform-origin in local units): head (100, 112); arm-l (62, 150); arm-r (138, 150); leg-l (84, 250); leg-r (116, 250); torso (100, 250).

**Build scale** (applied by player CSS through `data-build`): child head ×1.25 and body ×0.78; teen ×1.08 and ×0.92; adult ×1.0 and ×1.0; elder ×1.0 and ×0.95 with the torso lowered 4 units.

**Expressions** (`data-expr`): `neutral`, `happy`, `surprised`, `worried`, `thinking`, `laughing`. Each is a variant group inside `eyes`, `brows` and `mouth`.

**Mouth shapes** (`data-mouth`, used for lip-sync): `closed`, `open_s`, `open_m`, `open_l`, `smile`.

**Poses** (`data-pose`, defined in `player.css` as transforms of the part groups): `idle` (slow breathing loop), `talk` (small arm gesture loop), `wave`, `point_right`, `point_left`, `walk` (0.8 s loop alternating legs and arms), `think`, `celebrate`, `shrug`, `surprised`. Facing is mirrored with `scaleX(-1)` on the actor wrapper.

**Parameter domains** (these become the catalog enums):

| Parameter | Values |
| --- | --- |
| build | child, teen, adult, elder |
| presentation | f, m |
| skin\_tone | 0 to 5 |
| hair\_style | short\_crop, side\_part, curly\_short, afro\_puff, long\_straight, ponytail, bun, braids, bald, thin\_elder |
| hair\_color | 0 to 5 |
| top style | tshirt, long\_sleeve, hoodie, collared\_shirt, dress\_long, tunic, jacket, school\_top |
| bottom style | trousers, shorts, skirt\_long, skirt\_knee, none |
| shoes | sneakers, sandals, school\_shoes |
| accessories | glasses\_round, glasses\_square, backpack, cap, scarf, watch, headband |
| head\_covering | none, hijab, cap, kufi |
| color\_token (clothes) | c-primary, c-secondary, c-accent, c-support, c-neutral-1, c-neutral-2, ink, paper |

Limit: at most 140 elements per assembled character.

### Test sample (`tests/unit/test_s5_cast.py`)

```python
def test_s5_golden():
    out = s5_cast.run(script=load("golden/script.json"), brief=load("golden/brief.json"),
                      catalog=load_catalog(), age_group="9-11",
                      llm=FakeLLM("s5_cast.json", reviewer="s5_review_clean.json"))
    script = load("golden/script.json")
    assert {c.key for c in out.characters} == {c["key"] for c in script["characters"]}
    assert [s.scene_id for s in out.settings] == [s["id"] for s in script["scenes"]]
    for c in out.characters:
        assert c.hair_style in CATALOG["character"]["hair_style"]
        assert 0 <= c.skin_tone <= 5 and 0 <= c.hair_color <= 5
    by_key = {c.key: c for c in out.characters}
    assert by_key["nadia"].build == "child" and by_key["mama"].build == "adult"   # age_years 9 and 35
    assert by_key["nadia"].presentation == "f" and by_key["karim"].presentation == "m"
```

| --- | --- |
| `hair_style: "mohawk"` | blocker (not in catalog) |
| `shoes: "heels"` | blocker (not in catalog) |
| `top.color_token: "#FF0000"` | blocker (raw hex, only palette tokens allowed) |
| `skin_tone: 7` | blocker |

| Retry after one failure, second output valid | 2 `stage_runs`, final `passed` |
